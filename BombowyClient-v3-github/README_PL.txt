BombowyClient v3.0 - Pełna paczka źródłowa do wgrania na GitHub i zbudowania pliku .jar

1. Wgraj wszystkie pliki z folderu BombowyClient-v3-github do swojego repozytorium GitHub.
2. GitHub Actions automatycznie zbuduje plik .jar w zakładce Actions -> Artifacts (lub lokalnie przez ./gradlew build).
3. W grze naciśnij ` (tylda) lub Right Shift, aby otworzyć nowe menu BombowyClient.
4. Kliknij kartę modułu, ikonę ustawień (zębatkę) lub przycisk Edytor HUD, aby dostosować wszystko pod siebie.
